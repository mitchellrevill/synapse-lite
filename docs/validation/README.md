# Validation status

The source baseline is v0.5.0-beta1. The workspace tests (167 passed, 5 ignored; two additional recovery-encoding example tests passed) and release build pass. Tests cover profile codecs and preservation, device framing/correlation, and simulated device behavior including raw low-power threshold restoration. Five opt-in live/network tests remain ignored; passing the suite does not establish hardware parity.

Seven runtime runs included the normal tray, native editor, device worker/listeners and observed descendants at 125% DPI. Presented-frame evidence covers dashboard, the source Performance view, its scrolled polling panel and presentation-only independent/hidden row states, keyboard Lighting and keyboard Customize. The largest working-set high-water was 23,474,176 bytes; sampled private committed memory peaked at 8,515,584 bytes. No process-owned TCP connection was observed. Independent/hidden render overrides did not send device changes. These results cover recorded views and intervals; they do not prove complete functionality, visual identity, long-term behavior or removal of all installed Razer components. The seven-view evidence is in performance-views.json. Three further current-build Performance checks after stale-control guards are in runtime-memory.json, with explicit configured/visible/independent counts; their maximum working set was 24,207,360 bytes, still below 100 MB. Each file records its exact executable digest and scope.
