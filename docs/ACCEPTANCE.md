# Acceptance criteria

The project is complete only when all requirements below are demonstrated against the current build. A passing parser test, a device database entry, or a successful idle-memory check is insufficient for broader claims.

| Requirement | Required evidence | Current state |
| --- | --- | --- |
| Fork the requested beta baseline | GitHub fork relationship and exact upstream tag/commit | Fork created; baseline pinned to v0.5.0-beta1 |
| Rust implementation using Secretarybird functionality | Buildable fork, source review and functional paths | Fork release builds; native editor and shared device dispatcher integrated |
| Pixel-for-pixel Synapse interface without bloat | REA source/component/cascade recovery, exact fonts/assets, all required screen states, rendered validation | Source Performance/Power/Lighting controls, palettes/color editor, keyboard geometry and functional profile modal integrated; native resize/capture/modal tests and local icon pixel checks pass; full native UI parity unproven |
| No ads, telemetry, account requirement or bundled offers | Runtime entry-point and dependency/source review plus network observations | Automatic network timer and update popups removed; no TCP observed in seven measured views; longer verification pending |
| Cross-compatible Secretarybird profiles | Native format round trips, unknown-field preservation, typed edits and conflict-safe imports | Expanded codec, aggregate-budget, identity, rename and connection-mode tests pass; GUI full native backup explicitly retains all devices/profiles/opaque fields; earlier CLI round trip through the actual upstream beta passed; upstream still drops unknown fields when saving |
| Cross-compatible Synapse profiles | Verified format codec, translated settings, opaque-field preservation, re-import into real Synapse | Source-verified Synapse4 codec plus GUI profile/macro selection, fresh-GUID inactive imports and partial corrupt-record previews pass synthetic tests; CLI remains strict; real-app acceptance, macro execution, linked apps and Synapse3 remain unresolved |
| Installed Ornata V2 functionality | Actual lighting/effect/mapping/macro/profile/restore tests per advertised feature | Saved/live brightness and exact raw restoration passed; guarded host Static lifecycle passes simulator checks; physical source Static API saved a fresh profile and accepted seven packets with controls/brightness unchanged after one policy refresh and shutdown; stock restarted; bounded Spectrum/Breathing worker progressed with unchanged controls at14.27/14.56fps after control sampling optimization; optical output, cadence, broader lifecycle, display/idle, mappings/macros and input recovery remain pending |
| Installed DeathAdder V3 HyperSpeed functionality | Actual wired/wireless sensitivity, polling, mappings/macros/profile/restore and reconnect tests | Fork wired DPI/polling/sleep-timeout/low-power-threshold/stage, hidden/disabled projection and activation checks with exact raw restoration passed; wireless/input/sleep-wake workflows pending |
| Driver/API coverage | Driver roles, control ABI evidence, implemented behavior and safe input/recovery verification | HID and custom control ABI partially recovered; read-only RZCONTROL queries pass; client-close selector lifetime identified; [unsigned Rust KMDF forwarding candidate](KERNEL-BUILD.md) compiled separately, source published, not loaded; no replacement driver or input parity |
| Stock RAM and CPU baselines | Repeatable sampled stock process/service inventory, metric definitions and workload | Original60-second desktop baseline plus repeatable30-second app/service sampler and public declared inventory; broader workload baseline pending |
| Combined memory below 100,000,000 bytes | Three representative runs of the final build including editor, tray and every replacement helper; working set and private bytes; declared stock-service state | Three passes of four native overlay views peak at25,538,560 working-set /11,010,048 sampled private bytes at125% DPI; earlier Performance/Power/Lighting checkpoints also below100MB; active host effects, large documents and final-build acceptance pending |
| Preserve input and recovery | Failed-command handling, safe restore, profile backup/import, hotplug, sleep/wake and process-exit tests | Controlled error recovery and captured-register restoration passed; hotplug, abrupt termination, full input and sleep/wake recovery remain unverified |

The UI reference deliberately excludes advertising/promotional/account/telemetry content requested for removal. Required device-control screens must not be replaced with static mockups. Missing functionality must remain visible as incomplete rather than being hidden by narrower acceptance criteria.

Private hardware evidence and actual profile documents remain outside the public source repository. Synthetic fixtures are identified as synthetic.
