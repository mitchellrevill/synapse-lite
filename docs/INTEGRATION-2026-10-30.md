# Combined implementation checkpoint, 30 October 2026

The existing feature-thread checkpoints are consolidated into the native Rust app.
This continues the Secretarybird v0.5.0-beta1 implementation; it is not full Synapse
feature parity. No new Codex threads were created for consolidation. Approved tabs
were preserved.

The earlier thirteen-feature integration supplies native Settings, Global
Shortcuts, Chroma dashboard, loop authoring, Audio/Ambient/Reactive/Starlight
foundations, source artwork/layout coverage, device API families, onboard recovery,
wireless lifecycle and lighting regression checks.

The newer checkpoints add shared gradient editing, layers/groups, composition
management, LED property copy/paste, viewport controls, quick selections and layout
remapping. Wheel, Breathing, Spectrum, Fire, Tidal and Ripple retain their specific
documented runtime/admission limits. Shared native controls now coexist with their
effect-specific field ownership and history.

Customize combines Keyboard, Mouse, Multimedia, Windows, Launch and Disable/Default
local assignment editing with guarded profile snapshots and Standard/Hypershift
layers. Sensitivity is a separate inert desired draft. The subsequent
[Profile Switch authoring](PROFILE-NAVIGATION-AUTHORING.md) checkpoint adds its
native form and local Save; key-triggered switching remains unimplemented.
Cross-category cleanup prevents earlier overlays/drafts from hiding a
later saved assignment. These checkpoints do not enable unverified input delivery.

Shared additions include cached device information, per-device battery alerts,
private local support reports, bounded legacy archive inspection, lazy artwork
caching, gated Identify, focused macro recording, explicit Linked Games migration
and local profile-store backup/restore. Battery edits preserve existing opaque
metadata and unrelated devices. Macro recording and manual host playback are
exclusive; stop, history, import/export and window-close recovery remain guarded.

The newer Macro stack includes mixed-input planning and ownership ledgers, native
key fields, standalone XML, host-action planning/launch/playback, close-drain
recovery, random-delay editing and the recovered paste-protocol compiler. Text and
physical input playback remain separate unresolved runtime work.

## Verification record

The private build's `BUILD-VALIDATION.json` records its exact source commit, checks,
remaining failures/limits and executable hashes. The adjacent manifest verifies
every distributed file. Tests use simulated transport, private temporary stores
and explicitly owned fixture programs/windows. Imported stock Studio exports are
read-only fixtures. Windows private-font registration requires host context; a
restricted run can fall back to Arial and is not accepted as visual validation.

Consolidation repairs include private-message/dialog collisions, competing drag
state, shared gradient stop movement, source/raw metadata preservation, overlay
composition, font-aware native checks and recording/playback exclusivity. Local
tests and release builds are not proof of physical delivery or pixel identity.

## Remaining acceptance

- Finish Profile Switch's trigger routing/ordered runtime, Ripple's panel/propagation,
  Tidal's radial runtime and the documented finite/input-driven effect modes.
- Prove common driver routing, physical key identity, input ownership, terminal
  delivery, cancellation/release, reconnect and recovery before enabling bindings,
  Hypershift, Snap Tap, key-triggered macros or held sensitivity behavior.
- Complete catalogue-wide family adapters and physical checks. Catalogue IDs,
  artwork and presets are declarations, not verified support for every product.
- Complete source import/export and existing-profile activation acceptance,
  including legacy codecs, referenced macros, game links and source re-import.
- Validate device-specific optical/sensor, wireless/onboard/pairing and lighting
  behavior. Bounded Identify remains disabled until restoration/ownership proof.
- Complete matched-geometry/DPI visual comparisons and fix the remaining native
  popup, control, module-icon and text differences; do not redesign approved tabs.
- Complete privacy/network verification and all three representative complete
  replacement runs with summed working set and private committed memory each
  below100,000,000 bytes, including required helpers. Partial UI or simulator
  measurements do not satisfy this gate.

Ads, vendor telemetry, Connect and Haptics remain excluded. The inventory-aligned
implementation goal remains active.
